# Contributing to ef-migration-diff

We welcome contributions to `ef-migration-diff`! Please follow these guidelines to help us maintain a high-quality project.

## How to Contribute

### 1. Fork and Clone
- Fork the repository on GitHub.
- Clone your fork locally:
  ```bash
  git clone https://github.com/YOUR_USERNAME/ef-migration-diff.git
  ```

### 2. Create a Branch
- Create a feature or bugfix branch:
  ```bash
  git checkout -b feature/my-new-feature
  ```

### 3. Make Your Changes
- Ensure you have the **.NET 10.0 SDK** installed.
- **Code Style:** 
  - Follow existing conventions in the codebase.
  - Provide XML documentation for public classes and methods.
  - **IMPORTANT:** Keep all author headers intact. Do not remove or alter existing author headers in any files.

### 4. Run Tests
- Write tests for your changes if applicable.
- Ensure all existing tests pass before submitting your PR:
  ```bash
  dotnet test
  ```

### 5. Submit a Pull Request
- Push your branch to your fork.
- Open a Pull Request against the main repository.

## Reporting Issues
- Use GitHub Issues to report bugs or suggest features.
- When reporting a bug, please include clear reproduction steps, expected behavior, and actual behavior.
