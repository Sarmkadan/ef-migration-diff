# GitHub Actions Integration

This guide shows how to wire ef-migration-diff into a GitHub Actions PR workflow so that every pull request targeting `main` automatically runs a schema diff and posts the results as a PR comment.

## Prerequisites

- .NET SDK installed on the runner (8.0+ recommended)
- `GITHUB_TOKEN` available (provided automatically by GitHub Actions)
- ef-migration-diff installed as a global .NET tool, or available via `dotnet run`

## Quick-Start Workflow

Copy the workflow below into `.github/workflows/migration-check.yml` in your application repository (not in the ef-migration-diff repository itself):

```yaml
name: Migration Diff Check

on:
  pull_request:
    branches: [main]

permissions:
  contents: read
  pull-requests: write

jobs:
  migration-diff:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout PR branch (full history)
        uses: actions/checkout@v4
        with:
          fetch-depth: 0          # required so both branches are available locally

      - name: Set up .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'

      - name: Install ef-migration-diff
        run: dotnet tool install --global ef-migration-diff

      - name: Run migration comparison
        id: diff
        run: |
          # Capture clean JSON from stdout; status messages go to stderr
          ef-migration-diff compare \
            --branch1 origin/main \
            --branch2 "${{ github.head_ref }}" \
            --format json \
            2>diff-status.txt | tee diff-output.json || true

          echo "exit_code=$?" >> "$GITHUB_OUTPUT"

          # Expose key counts for the summary step
          CONFLICTS=$(jq '.Conflicts | length' diff-output.json)
          SCHEMA_CHANGES=$(jq '(.SchemaChanges.Source | length) + (.SchemaChanges.Target | length)' diff-output.json)
          RESULT=$(jq -r '.Result' diff-output.json)
          echo "conflicts=$CONFLICTS"     >> "$GITHUB_OUTPUT"
          echo "schema_changes=$SCHEMA_CHANGES" >> "$GITHUB_OUTPUT"
          echo "result=$RESULT"           >> "$GITHUB_OUTPUT"

      - name: Post PR comment
        if: always()
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const result       = '${{ steps.diff.outputs.result }}';
            const conflicts    = parseInt('${{ steps.diff.outputs.conflicts }}', 10);
            const schemaChanges = parseInt('${{ steps.diff.outputs.schema_changes }}', 10);

            const icon = conflicts > 0 ? '⚠️' : '✅';
            const statusLine = conflicts > 0
              ? `**${conflicts} conflict(s) detected — review required before merge.**`
              : 'No migration conflicts detected.';

            // Embed a short JSON snippet if the file exists
            let jsonSnippet = '';
            try {
              const raw = fs.readFileSync('diff-output.json', 'utf8');
              const parsed = JSON.parse(raw);
              jsonSnippet = '```json\n' + JSON.stringify({
                result: parsed.Result,
                conflicts: (parsed.Conflicts || []).length,
                sourceOnly: (parsed.Migrations?.SourceOnly || []).length,
                targetOnly: (parsed.Migrations?.TargetOnly || []).length
              }, null, 2) + '\n```';
            } catch {}

            const body = [
              `## ${icon} EF Migration Diff — ${result}`,
              '',
              statusLine,
              '',
              `| Metric | Value |`,
              `|--------|-------|`,
              `| Conflicts | ${conflicts} |`,
              `| Schema changes | ${schemaChanges} |`,
              '',
              jsonSnippet,
              '',
              '<sub>Generated by ef-migration-diff</sub>'
            ].join('\n');

            await github.rest.issues.createComment({
              owner: context.repo.owner,
              repo:  context.repo.repo,
              issue_number: context.issue.number,
              body
            });

      - name: Fail if blocking conflicts
        if: steps.diff.outputs.conflicts > 0
        run: |
          echo "Blocking migration conflicts detected. See PR comment for details."
          exit 1
```

## How It Works

1. **Full fetch** (`fetch-depth: 0`) ensures both `origin/main` and the PR branch are available locally without a `git checkout`.
2. **ef-migration-diff** runs with `--format json`. The JSON report goes to stdout; status lines go to stderr. `tee` saves the JSON to a file while still streaming it.
3. **`actions/github-script`** reads the JSON and posts a structured Markdown comment on the PR.
4. The job **fails** if any blocking conflicts are found, gating the merge.

## Azure SQL / SQL Server Notes

If your project targets Azure SQL, no extra steps are required — ef-migration-diff analyses migration files at the source level and does not connect to a live database. You do **not** need to pass connection strings.

## Multi-DbContext Projects

For projects with multiple DbContexts, run a separate step per context:

```yaml
      - name: Compare AppDbContext migrations
        run: |
          ef-migration-diff compare \
            --branch1 origin/main \
            --branch2 "${{ github.head_ref }}" \
            --format json \
            --db-context AppDbContext \
            2>/dev/null | tee app-diff.json || true

      - name: Compare AuditDbContext migrations
        run: |
          ef-migration-diff compare \
            --branch1 origin/main \
            --branch2 "${{ github.head_ref }}" \
            --format json \
            --db-context AuditDbContext \
            2>/dev/null | tee audit-diff.json || true
```

## Fail-Only Mode (No Comment)

If you only need to block merges on conflicts without posting a comment:

```yaml
      - name: Check for migration conflicts
        run: |
          ef-migration-diff compare \
            --branch1 origin/main \
            --branch2 "${{ github.head_ref }}"
```

The tool exits with code `1` when blocking conflicts are detected, which fails the workflow step automatically.

## Caching the Tool Between Runs

```yaml
      - name: Cache .NET tools
        uses: actions/cache@v4
        with:
          path: ~/.dotnet/tools
          key: dotnet-tools-ef-migration-diff-${{ runner.os }}

      - name: Install ef-migration-diff (if not cached)
        run: dotnet tool install --global ef-migration-diff || true
```
